# Happy-new-year-wish-sinhala-hindu-new-year-wish 🎉

This is a simple open-source webpage to share **Sinhala & Hindu New Year (Aluth Avurudu)** greetings for **2025**.  
Perfect for sharing a warm wish with friends, family, and your community! 🇱🇰
<!-- ![Logo](https://dev-to-uploads.s3.amazonaws.com/uploads/articles/th5xamgrr6se0x5ro4g6.png) -->

![Preview of webpage](assets/preview.gif)



## 🌟 What’s Inside?

- Neothemed web page
- A single static HTML file (`index.html`)
- Responsive and colorful design
- Ready-to-use New Year greeting
- no frameworks – just pure HTML , CSS & JavaScript,
- Assets: 📷 Screenshot & 🎞️ Animated preview in assets/
